# Lógica de Programación en Java — Universidad del Quindío

Repositorio académico dedicado al aprendizaje de Java, la resolución de problemas y el desarrollo del pensamiento computacional durante la asignatura **Lógica de Programación**, del programa de Ingeniería de Sistemas y Computación de la Universidad del Quindío.

Aquí se recopilan ejercicios, talleres, ejemplos de clase y proyectos de práctica desarrollados a lo largo del proceso de aprendizaje. El repositorio también incluye ejercicios complementarios para reforzar los conceptos estudiados y adquirir bases sólidas antes de avanzar hacia la Programación Orientada a Objetos (POO).

## Objetivos

- Consolidar los fundamentos de Java: variables, constantes, tipos de datos, operadores y expresiones.
- Comprender las estructuras de control, los ciclos, los métodos y las estructuras de datos.
- Desarrollar el pensamiento computacional mediante la resolución práctica de problemas.
- Organizar y documentar el código para facilitar su lectura, mantenimiento y consulta.
- Construir una base sólida para continuar con Programación Orientada a Objetos.

## Contenido del repositorio

El repositorio reúne ejercicios académicos y proyectos de práctica relacionados con los siguientes temas:

| Tema | Contenido |
|---|---|
| Fundamentos de Java | Sintaxis, comentarios, variables, constantes y tipos de datos. |
| Operadores | Aritméticos, asignación, comparación, lógicos y unarios. |
| Expresiones | Expresiones aritméticas, relacionales y lógicas. |
| Condicionales | Decisiones con `if`, `else` y `switch`. |
| Ciclos | Repetición de instrucciones mediante estructuras iterativas. |
| Métodos | Modularización y reutilización del código. |
| Estructuras de datos | Arrays y, posteriormente, otras colecciones de Java. |
| Talleres académicos | Ejercicios y actividades de la asignatura. |
| Proyectos de práctica | Programas desarrollados para explorar y aplicar los conceptos aprendidos. |

Los archivos se irán organizando y documentando progresivamente para facilitar su consulta conforme avance la asignatura.

## Ruta académica principal: Universidad del Quindío

La prioridad del repositorio es acompañar el proceso de formación en la asignatura de Lógica de Programación.

Esta sección reúne los ejercicios, talleres y ejemplos relacionados con las explicaciones de clase y las orientaciones de la docente. Su contenido se irá ampliando conforme se desarrollen nuevas actividades y se estudien otros temas.

El código se utiliza como material de aprendizaje: las soluciones pueden modificarse, corregirse y ampliarse para comprender mejor los problemas y las distintas formas de resolverlos.

## Metodología de estudio

1. Revisar la explicación de clase y resolver primero las actividades académicas correspondientes.
2. Repasar el tema con el curso complementario cuando necesite otra explicación o ejemplos.
3. Escribir el código, ejecutarlo y comprobar los resultados.
4. Modificar los ejemplos para entender cómo cambian las salidas del programa.
5. Registrar los ejercicios terminados y corregir los errores antes de avanzar.

Las casillas de la ruta complementaria permiten llevar un registro personal del progreso. Se pueden marcar cuando cada tema haya sido estudiado y practicado.

## Propósito académico y licencia

Este repositorio tiene fines educativos. El código se desarrolla para practicar Java, reforzar los contenidos de la asignatura y documentar el proceso de aprendizaje.

Las soluciones pueden contener errores o cambiar a medida que se profundicen los conceptos. Por ello, se recomienda leer el código, ejecutarlo y verificar sus resultados en lugar de utilizarlo sin comprenderlo.
